FAQ

Frequently asked questions

What is a HEX color code?

A HEX code is a six-character code that starts with # and describes a color for screens — for example #FF0000 is pure red. The pairs of characters set the amount of red, green and blue from 00 (none) to FF (full).

How many named colors are there in HTML and CSS?

Browsers recognise 148 named colors, such as coral, navy, teal and rebeccapurple. Some names share a code: aqua and cyan are both #00FFFF, and fuchsia and magenta are both #FF00FF.

Can I use these color names in CSS?

Yes. Any name in this chart works directly in CSS, for example color: tomato;. For brand work, HEX codes are safer because they're exact and work in every design tool.

How do I find the code for a color I see?

Search this chart by name, or use a color picker to grab it, then paste it into the color converter to get HEX, RGB, HSL and CMYK — plus the closest named color.

Are these colors the same in print?

Not exactly. These are screen (RGB) colors. Printers use CMYK inks, and some bright screen colors can't be printed exactly. Use the CMYK & Pantone guide before sending files to print.
